OpenFront — Offline Solo

This is the Chromebook-only Solo package you supplied. The Solo simulation runs in the browser; it does not need a public multiplayer server or your PC.

First-time setup on your Chromebook

  1. Enable the Chromebook Linux development environment.
  2. Move OpenFront_Solo_Offline_Chromebook.zip into Linux files.
  3. Open the Linux Terminal and run:
cd ~
unzip -q OpenFront_Solo_Offline_Chromebook.zip
cd ~/OpenFrontOffline
bash start-openfront.sh

Keep the Terminal window open while playing. The local server only serves the bundled files to this Chromebook. Press Ctrl+C in Terminal when finished.

Launch OpenFront Offline

The ZIP expands to roughly 722 MB. Sign-in, cosmetics, cloud saves, public lobbies, and archived-game uploads are not part of this offline package. OpenFront code is AGPL-3.0 and included assets are CC BY-SA 4.0; keep the supplied license and attribution files with the package.
