OpenFront.io

The official OpenFront website now blocks its game page from being embedded inside other websites. The browser enforces that rule, so changing The Universe's iframe settings cannot override it.

To run OpenFront in this viewer, The Universe needs a self-hosted OpenFront client build and a compatible game-server connection. A simple HTML wrapper or proxy will not make the public page embeddable.

Game launch is paused until the OpenFront build is available.
